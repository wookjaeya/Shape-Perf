# SPEC rev 1.3 통합 변경표

- 작성: 2026-10-22. 대상: `Architecture/spec/SPEC_FINAL.md` rev 1.2 (3,702줄).
- 입력: 명세안 0.2(사용자 업로드, 이하 "0.2"), PI 결정 `Architecture/spec/PI_DECISIONS_RESOLVED_20261022.md`(D1–D5), 검토 `REVIEW_PROPOSAL_20261022.md`.
- 성격: **변경 계획표**다. SPEC 본문은 아직 바꾸지 않았다. 각 행은 rev 1.3에서 할 편집 하나이며, 적용은 이 표의 순서(§3)로 한다.
- 원칙(0.2 §0.1, D1): rev 1.2의 정의(상태, 세 판단, 출처, σ·M, Allowed, horizon)는 **유지**하고, 우선순위·완료 조건·주장 범위·결과 요약만 바꾼다. 삭제는 없다. 내려가는 경로(인증서·탐색기·진행성)는 "선택 경로"로 표시만 바꾼다.
- 표기: **유지** / **수정** / **추가** / **표시 변경**(본문 유지, 필수→선택 등 지위만 바꿈). "근거"는 0.2 절 또는 결정 ID.

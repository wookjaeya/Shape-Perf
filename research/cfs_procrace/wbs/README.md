# WBS 관리 규칙

- 이 디렉터리에는 WBS만 둔다. 기준 파일은 `WBS_DECISIONS_20261111.md`다.
- 의사 결정과 계획·판단의 수정은 WBS를 토대로 한다. 작업 산출물(코드, 분석 문서, 기록)은 이 디렉터리 밖에 두고, 자신이 따르는 WBS 항목(WP 번호나 절 번호)을 적는다.
- WBS의 §0–§20 본문은 PI가 고친다. lead는 §21(진행 기록과 갱신)에만 적는다. 본문과 달라진 현재 상태, 새로 고려할 핵심 사항, 묶음의 종료 여부를 날짜와 근거와 함께 적는다.
- 작업 에이전트는 WBS를 읽기만 한다. WBS를 고치는 커밋은 다른 변경과 섞지 않고 제목을 `WBS:`로 시작한다.
- PI가 새 판을 올리면 본문을 그 판으로 바꾸고, §21은 이어 붙여 보존한다.
- **WBS는 PI와 lead가 이 작업을 고려하고 논의하는 틀이다(PI 지시, 2026-11-16).** 논문이나 연구와 관련된 어떤 서술이나 참조에도 쓰지 않는다. 연구 문서, 코드와 주석, 도구 출력, 기록, 연구 산출물의 커밋 메시지에 "WBS", WBS의 절 번호, 작업 묶음 번호(WP…)를 적지 않는다. 연구 산출물의 근거는 코드·기록·문헌·PI 결정 같은 1차 근거로만 적는다. 어느 작업 묶음이 어떤 산출물을 냈는지는 WBS의 §21에만 적는다.

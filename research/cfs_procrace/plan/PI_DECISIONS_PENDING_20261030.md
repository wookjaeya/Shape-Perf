### B2. `kz predict`의 거취 (RP §10 항목 2)

  - [F] RV2: `.kzm`은 자동 탐지 입력에서 중단한다. 엔진 전체는 즉시 삭제하지 않고, 자동으로 만든 의존 부분과 제약을 처리할 수 있는지 감사한 뒤 정한다(RV2 L490–L491).
  - [F] W6 hold 계획 28개는 손으로 쓴 모델에서 생성됐다(IA:631). 앞선 계획 9개는 디스크에 없다(IA:787).
  - [F] RA §3.1의 반사실 신호는 predict의 "결과 뒤집기"와 같은 질문이고, 입력만 추출 사실이다(RA:51).
  - [F] SPEC 반증표 셋째 줄 "실행 너머의 실제 잠재 위반"은 기록에 없는 후보의 같은 기반 확인, 또는 정당화된 예측 보장을 요구한다(SPEC:869).
  - [I] predict를 빼면 "예측했으나 돌리지 않은 후보" 등급이 없어지고, 잠재 후보는 확인 실행으로만 선다.
  - [U] `relations`의 실현 가능성 칸이 몇 행 "결정 불가"로 남는지는 2a 뒤에 나온다. (개정 1 시점)
  - [M] 2a 뒤(개정 4, 셋째 수정 둘째 차례): 실현 가능성 등급은 다섯 빌드에서 undecidable 318 / 318 / 254 / 147 / 147, possible 112 / 112 / 79 / 11 / 0, proven-impossible 0 / 0 / 0 / 6 / 14, not graded 1 / 1 / 5 / 14 / 14다(행 431 / 431 / 338 / 178 / 175, AR §6). 첫째 차례의 not graded 2 / 2 / 1 가운데 C1 둘·R2 하나는 전제 없이 "닿지 않음"이라 한 행이었다(타임베이스 자식의 풀리지 않은 간접 호출, union 멤버로 읽는 정적 이미지: AR §13 #7, #9); 그 셋은 `undecidable`이 되었고, 그 자식이 주소가 잡힌 함수를 거쳐 닿을 수 있는 새 행 20 / 20 / 33 가운데 1 / 1 / 5가 근거를 적은 `not graded`다. 셋째 수정 첫째 차례의 수는 undecidable 297 / 297 / 225 / 147 / 147, not graded 2 / 2 / 1 / 14 / 14(행 411 / 411 / 305 / 178 / 175)였다. 둘째 수정의 not graded 20 / 20 / 5 가운데 C1 18·R2 2는 "자식이 닿지 않음"이 틀린 행이었다(자식이 시작하는 스레드가 닿음, 또는 스레드 집합이 완전하지 않음: AR §12 #12). A 행은 늘 undecidable이고, B 행은 펼친 table walk의 생성 순서만 읽어 "fixed unconfirmed"도 undecidable이다(AR §1.2). 그래서 기준 ②의 앞 절("결정 불가 행이 남는다")은 섰다. 뒤 절("실행 없이 가를 수단이 predict뿐")은 정하지 않았다 [I]. 기준 ①은 relations 행의 계층이 B/P0/L0/R뿐이라 섰지만(AR §4 T5), 그 행들은 `rests-on`(B4)과 `P0-unverified`(A4)를 단다.

  - [M] 지금 분석 빌드는 C1 pre/post(번들 1df262a), R2 core, C5 6.4.1/6.4.2다(S2:20).

### C3. 일반화 근거와 규칙 동결

- **질문**: 다섯 사례(개발·회귀 집합) 밖의 일반화 근거를 무엇으로 삼고, 규칙 동결 시점과 동결 뒤 대상 선정자를 어떻게 하는가?

  - [F] 합성 코드는 추출기·정체성·동기화의 단위 검증에 한정한다(RV2 L478).
  - [F] D8/P-RECALL(10-15)은 "다섯 사례 먼저, 추가 평가는 별도"로 정했다. 변이 연산자·이력 질의·질의 실행자 등은 미결이다(PID:403–PID:405).

### C4. 참·거짓·미확인의 정의와 정밀도 보고

- **질문**: 후보마다 참(위반 확인)·거짓(오탐 확인)·미확인을 무엇으로 정하고, 정밀도와 집계를 어떻게 보고하는가?

  - [F] 위반 근거는 "관측된 실패 결과 + 반대 순서 실현 가능성, 또는 실현된 강제 순서"다(RV2 §5.4 L341–L351, ED:528). 확인 실행 결과는 일곱 가지이고, 뒤 다섯 가지를 "무해"로 단정하지 않는다(RV2 §3.8).

  - [I] RV2는 "거짓(F)"이 무엇인지 정의하지 않는다. 정의가 없으면 거의 모든 후보가 U로 남아 범위가 0~1에 가깝게 벌어진다.
  - [F] 규모의 신호: 원형 관측점 규칙만으로 C1 OP-B가 1,131개다(ED:36). 실제 relations 행 수는 2a 뒤에 나온다 [U]. (개정 1 시점)

### C6. C2(cFE #198)의 처리
